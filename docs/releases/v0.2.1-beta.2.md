## 简体中文

这是一次小型补丁 Beta，修复 Harness 更新后主页面入口错位、未配置状态下余额区域挤压，以及自定义视觉模型无法在设置中声明图片能力的问题。

### 修复

- 主页面更新入口改为固定在侧栏右下角的图标按钮，不再依赖 Harness 品牌行的 DOM 结构；侧栏或窗口尺寸变化时会重新定位。
- 账户余额的标签和状态改为纵向排布，起始图标与“设置”对齐；未配置 API Key 时说明文字不会再挤出侧栏。
- 自定义模型的展开设置中新增“输入能力”，可选择“自动继承”“仅文本”或“文本与图片”。能力只写入当前模型，不会污染同一 Provider 下的其他模型。

模型能力控件目前作为针对 Harness `0.1.0-rc.7` 的版本限定临时补丁交付。升级 Harness 时构建会要求人工复核；官方提供相同能力后可以安全撤回，已经保存的 `models[].input` 仍是官方 adapter 支持的合法配置。

### 下载与安装

推荐下载 Apple Silicon DMG：

[下载 DeepSeek.YukiRyou-0.2.1-beta.2-arm64.dmg](https://github.com/yoshino-xiao7/deepseek-harness-desktop-yukiryou/releases/download/v0.2.1-beta.2/DeepSeek.YukiRyou-0.2.1-beta.2-arm64.dmg)

打开 DMG 后，将 **DeepSeek YukiRyou** 拖入“应用程序”。覆盖安装不会删除 Harness 的会话、凭据、设置或工作区数据。

## English

This patch Beta fixes the misplaced main-window update entry after Harness UI changes, cramped account-balance copy before model configuration, and the missing image-capability control for custom vision models.

### Fixes

- The main-window update entry is now an icon button anchored to the sidebar's bottom-right corner instead of depending on the Harness brand-row DOM. It is repositioned when the sidebar or window changes size.
- The account-balance label and status now stack vertically, with the leading icon aligned to Settings. The unconfigured API-key message no longer overflows the sidebar.
- Each custom model now has an Input capability control with Automatic/inherit, Text only, and Text and images options. The selection applies only to that model and does not mark every model on the provider as multimodal.

The model-capability control is delivered as a reversible, version-scoped patch for Harness `0.1.0-rc.7`. A Harness upgrade requires explicit review; once upstream provides the control, the patch can be removed safely, while saved `models[].input` values remain valid adapter configuration.

### Download and install

The Apple Silicon DMG is recommended:

[Download DeepSeek.YukiRyou-0.2.1-beta.2-arm64.dmg](https://github.com/yoshino-xiao7/deepseek-harness-desktop-yukiryou/releases/download/v0.2.1-beta.2/DeepSeek.YukiRyou-0.2.1-beta.2-arm64.dmg)

Open the DMG and drag **DeepSeek YukiRyou** into Applications. Installing over an existing copy does not remove Harness sessions, credentials, settings, or workspace data.
