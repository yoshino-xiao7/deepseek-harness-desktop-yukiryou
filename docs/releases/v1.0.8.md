## 简体中文

`v1.0.8` 将内置 DeepSeek Harness 升级到 `0.1.2-rc.1`，并完成桌面端对新浏览器鉴权与拆分 Runtime 依赖的适配。

### Runtime 升级

- **固定 rc.1 完整依赖图：** 内置 `@deepseek-ai/dsh@0.1.2-rc.1`，显式冻结全部非可选 Peer、安装脚本 allowlist 与 npm 完整性，继续提供离线、可复现的 Runtime。
- **新增 rc.1 Runtime Home 回退代际：** 首次打开非空数据前创建 `runtime.pre-dsh-0.1.2-rc.1[.N]` 副本；既有历史回退副本不会被覆盖或复用。
- **迁移 Client 插件组合：** 桌面插件不再依赖已拆分的 `dsh-client-runtime`，改用 rc.1 细粒度 Client providers；逐轮变更读取改用持久化工具结果元数据。

### 安全与兼容性

- **适配浏览器启动鉴权：** Supervisor 校验 Harness 输出的启动 URL，以一次性 token 换取 HttpOnly/SameSite Cookie，再执行首页与受保护 Companion RPC 的就绪验证。
- **限制凭据作用域：** 主进程的 Companion 与 Market 请求只允许访问当前回环 origin；跨域请求失败关闭，启动 token 与 Cookie 不进入可序列化状态或日志。
- **保持真实浏览器路径：** Electron 首次导航使用受保护 URL，Harness 重定向后回到干净 origin；E2E 与升级门禁复用 Electron Session Cookie。
- **复核临时补丁：** 模型输入能力、会话选择恢复与上下文容量 Tooltip 补丁在 rc.1 实际 bundle 中仍有必要，已重新定位并保留严格版本保护。

### 发布门禁

- 本地已完成 Runtime 装配与校验、类型检查、lint、单元测试及真实 rc.1 集成验证。
- 正式发布仍须通过 macOS 签名/公证/安装与更新闭环，以及 Windows 11 x64 Setup/portable 生命周期门禁；未通过前不会覆盖已发布标签。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.8` upgrades the bundled DeepSeek Harness to `0.1.2-rc.1` and adapts the desktop application to its new browser authentication and split Runtime dependencies.

### Runtime upgrade

- **Pins the complete rc.1 dependency graph:** bundles `@deepseek-ai/dsh@0.1.2-rc.1` with every non-optional peer, install-script allowlist entry, and npm integrity value explicitly frozen for reproducible offline startup.
- **Adds a new Runtime Home rollback generation:** preserves a non-empty home as `runtime.pre-dsh-0.1.2-rc.1[.N]` before first access without overwriting or reusing older rollback copies.
- **Migrates Client plugin composition:** desktop plugins replace the removed `dsh-client-runtime` aggregate with rc.1's focused Client providers, while per-turn changes now read durable tool-result metadata.

### Security and compatibility

- **Supports browser launch authentication:** the Supervisor validates Harness's launch URL, exchanges its one-time token for an HttpOnly/SameSite cookie, and then verifies both the home page and protected Companion route.
- **Scopes credentials to one origin:** main-process Companion and Market requests can only reach the current loopback origin. Off-origin access fails closed, and launch tokens and cookies never enter serializable state or logs.
- **Preserves the real browser flow:** Electron performs its first navigation with the protected URL and continues on the clean origin after Harness redirects; E2E and upgrade gates reuse the Electron Session cookie.
- **Revalidates temporary patches:** the model-input capability, session-selection recovery, and context-meter Tooltip patches remain necessary in the actual rc.1 bundles and retain strict version guards.

### Release gates

- Local Runtime vendoring and verification, type checking, lint, unit tests, and real rc.1 integration checks have passed.
- Publication still requires the macOS signing, notarization, installation, and update loop plus the Windows 11 x64 Setup/portable lifecycle gates. Published tags will not be overwritten.

> This is an independent community project, not an official DeepSeek client.
