## 简体中文

`v0.2.3-beta.2` 是 Windows 11 x64 启动与平台显示热修复，同时重新发布经过相同版本门禁验证的 macOS 资产。

### 修复内容

- Windows 普通用户首次启动不再依赖管理员权限或 Developer Mode；桌面扩展使用目录 junction 装配。
- Windows 首次组装固定 Runtime 时最多等待 60 秒，避免在较慢机器上停留于“正在唤醒 Harness”。
- “关于”和手动更新界面会正确显示 Windows x64、Setup EXE 与便携 ZIP，不再出现 Apple Silicon、macOS 或 DMG 文案。

### Windows 真机验证

真实 Windows 11 x64 非管理员交互桌面已验证：固定 Runtime 装配、完整桌面功能/UI、打包应用和便携 ZIP 启动/重启、Squirrel 首次安装、已安装应用启动、同版本修复安装、卸载清理及用户数据保留。

Windows 提供两份未签名产物：

- `DeepSeek.YukiRyou-0.2.3-beta.2-win32-x64-Setup.exe`
- `DeepSeek.YukiRyou-win32-x64-0.2.3-beta.2-portable.zip`

当前不做 Authenticode 签名，Windows 可能显示 SmartScreen 警告。请只从本 Release 下载并核对 `SHA256SUMS-Windows.txt`。

`v0.2.3-beta.1` 的 Windows 资产存在普通用户无法启动的问题；待本版公开并核验后会从旧 Release 移除，旧版 macOS 资产保留。

> 这是社区独立 Beta，不是 DeepSeek 官方客户端。

## English

`v0.2.3-beta.2` is a Windows 11 x64 startup and platform-presentation hotfix. macOS artifacts are republished after passing the same version gate.

### Fixes

- First launch on Windows no longer requires administrator privileges or Developer Mode; desktop extensions are assembled with directory junctions.
- Windows cold startup now allows up to 60 seconds for the pinned Runtime to assemble on slower machines.
- About and manual-update surfaces now show Windows x64, Setup EXE, and portable ZIP instead of Apple Silicon, macOS, or DMG copy.

### Real Windows validation

An interactive, non-administrator Windows 11 x64 desktop verifies pinned Runtime assembly, the complete desktop feature/UI E2E, packaged and portable ZIP startup/restart, first Squirrel install, installed startup, same-version repair, uninstall cleanup, and user-data retention.

Windows ships two unsigned artifacts:

- `DeepSeek.YukiRyou-0.2.3-beta.2-win32-x64-Setup.exe`
- `DeepSeek.YukiRyou-win32-x64-0.2.3-beta.2-portable.zip`

They are intentionally not Authenticode-signed, so Windows may show a SmartScreen warning. Download only from this Release and verify `SHA256SUMS-Windows.txt`.

The Windows assets in `v0.2.3-beta.1` cannot start reliably for ordinary users. They will be removed from the old Release after this version is published and verified; the old macOS assets remain available.

> This is an independent community beta, not an official DeepSeek client.
