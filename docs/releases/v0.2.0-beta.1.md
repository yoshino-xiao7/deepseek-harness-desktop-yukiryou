这是继 `v0.1.1-beta.1` 之后的功能 Beta，重点加入账户余额、Desktop Companion、工作区文件浏览和只读变更审核。

## 本次更新

- **账户余额**：在 Harness“设置”上方显示当前 DeepSeek 凭据所属账户的 CNY/USD 余额；不显示无法由官方接口精确提供的今日消费。
- **Desktop Companion**：主窗口新增与 Harness 风格一致的可收起右栏，并使用同步动画调整 Harness 可用宽度。
- **文件与变更**：右栏提供当前工作区文件树、相对 HEAD 的 Git 变更、增删行统计和红删绿增的单文件 diff。
- **文件预览**：支持 Markdown 排版/源码切换、纯文本和常见图片预览；历史轮次 Markdown 变更始终进入审核 diff。
- **逐轮变更卡**：保留官方“产物”入口，并在下方展示由 Harness 工具事件确认的本轮变更文件。
- **Harness rc.7**：内置 Runtime 升级到 DeepSeek Harness `0.1.0-rc.7`，并完成 node-pty、PTY 往返、sharp 与 koffi 原生门禁。

## 安全与可靠性

- 本地 shell 与 Harness 使用独立 preload；文件能力不会暴露给 Harness 页面。
- Workspace root 必须由 Runtime registry 重新确认，renderer 只能提交随机节点 ID，不能提交绝对路径或 shell 命令。
- 文件读取使用 `O_NOFOLLOW`，读取前后校验文件身份；非法 UTF-8、超限文件和图片像素炸弹会被拒绝。
- Markdown 只渲染 SafeMarkdown 结构；HTML、SVG/MathML、远程图片、iframe、事件属性和脚本链接均为不可执行文字。
- 已通过 2500 次侧栏/标签长会话内存门禁、0.1.0 Runtime Home 保留验证和打包应用持续健康资格测试。

## 下载与安装

推荐下载 Apple Silicon DMG：

[下载 DeepSeek.YukiRyou-0.2.0-beta.1-arm64.dmg](https://github.com/yoshino-xiao7/deepseek-yukiryou/releases/download/v0.2.0-beta.1/DeepSeek.YukiRyou-0.2.0-beta.1-arm64.dmg)

打开 DMG 后，将 **DeepSeek YukiRyou** 拖入“应用程序”。覆盖安装不会删除 Harness 的会话、凭据、设置或工作区数据。

系统要求：Apple Silicon Mac（M1 或更新芯片）、macOS 14 或更高版本。

## 已知限制

- 当前仍为 Beta，建议重要工作保留项目与配置备份。
- Desktop Companion 当前为只读审核，不提供撤销、提交或推送按钮。
- 宠物活动区尚未加入，将在角色素材冻结后单独实现。
- 暂不支持 Intel Mac、Windows 或 Linux。
- 本项目由社区独立开发，与 DeepSeek 官方没有隶属或背书关系。

遇到问题请前往 [GitHub Issues](https://github.com/yoshino-xiao7/deepseek-yukiryou/issues) 反馈，并附上 macOS 版本、应用版本和复现步骤。
