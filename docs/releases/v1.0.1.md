## 简体中文

`v1.0.1` 是 DeepSeek YukiRyou 的首个稳定版修复更新，集中处理账户信息、工作区实时刷新、社区插件管理、主题同步、Codex 登录和上下文容量悬浮区域的可靠性问题。

### 本次修复

- **账户信息可靠加载**：余额请求与今日用量统计不再互相阻塞。慢速会话统计会在后台完成，进入应用时无需反复刷新才能看到余额；V4 Flash、Vision Exp 与 Pro 的 usage 均进入本机今日估算。
- **工作区保持实时**：Workspace Review 默认收起，当前工作区和 Git 状态变化会自动刷新；当原生文件 watcher 丢失嵌套事件时，低频校正会补上通知。路径、行号和文件复制信息继续清晰显示。
- **插件市场不再长时间阻塞**：过期的持久目录立即显示，并在后台刷新。刷新期间保留搜索、筛选、已安装列表和详情，不再把整个设置页清空。
- **已安装插件更易管理**：默认只显示用户自行安装的插件，可切换查看系统与依赖。受管插件直接查询 npm 最新稳定版本，不必等完整社区索引结束；实际更新仍必须通过目录来源和完整安全预检。
- **主题同步完整**：模型切换或深浅色变化后，本地顶栏和 Workspace Review 会同步前景色、边框、强调色及表面颜色，减少第三方皮肤偶发恢复为系统视觉的现象。
- **Codex 登录中转窗口**：允许 Harness 创建受限的 `about:blank` OAuth 中转窗口，再把唯一外部导航交给系统浏览器；其他弹窗仍被拒绝。
- **上下文容量悬浮稳定**：对固定的 Harness `0.1.1-rc.2` 应用可撤回临时补丁，停用会错位并引起闪烁的 Tooltip，同时保留原按钮、点击详情、无障碍标签和原生悬浮说明。
- **窗口大小自动恢复**：退出前保存最后一次正常窗口大小、位置与最大化状态，下次启动直接恢复。若原外接显示器已移除，窗口会自动移回当前主屏，不会留在屏幕外。
- **原生菜单一致性**：macOS 与 Windows 菜单随 Harness 语言完整切换，不再出现中英文混排；正式版隐藏 Developer Tools 和强制刷新，并只保留一个全屏入口。

### 下载

## English

`v1.0.1` is the first stable maintenance update for DeepSeek YukiRyou. It focuses on account loading, live workspace refresh, community plugin management, theme synchronization, Codex sign-in, and the context meter hover surface.

### Fixes in this release

- **Reliable account loading:** balance requests and today's local usage estimate no longer block each other. Slow session aggregation can finish in the background, while usage from V4 Flash, Vision Exp, and Pro is included in the estimate.
- **Live workspace state:** Workspace Review starts collapsed and refreshes as workspace or Git state changes. A low-frequency reconciliation catches nested events silently dropped by the native watcher, while copied paths, line numbers, and file details remain readable.
- **Non-blocking plugin catalog:** an expired persistent snapshot is displayed immediately and refreshed in the background. Search, filters, installed entries, and details remain usable during refresh.
- **Clear installed plugin management:** the installed view defaults to user-installed plugins and can reveal system or dependency entries on demand. Managed plugins query npm's latest stable version directly; catalog provenance and the full safety inspection remain mandatory before applying an update.
- **Complete theme synchronization:** model or light/dark changes now propagate foreground, border, accent, and surface tokens to the local title bar and Workspace Review, reducing occasional fallback to built-in styling with third-party skins.
- **Codex sign-in relay:** Harness may create a restricted `about:blank` OAuth relay whose single external navigation is handed to the system browser. Other popups remain denied.
- **Stable context meter hover:** a reversible patch scoped to Harness `0.1.1-rc.2` disables the misplaced flickering Tooltip while preserving the button, click-open details, accessible label, and native hover copy.
- **Restored window geometry:** the last normal bounds, position, and maximized state are restored on the next launch. If the previous external display is gone, the window is safely moved back onto the current primary display.
- **Consistent native menus:** macOS and Windows menus now follow the Harness locale without mixed-language system roles. Production menus omit Developer Tools and force reload, and expose only one full-screen command.

### Downloads

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: guided Setup EXE with a selectable destination and a portable ZIP.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

Installations in mainland China prefer `download-cn.suzuki.ink` and fall back to GitHub; other regions prefer GitHub. The China mirror is updated only after the GitHub stable Release is public and every artifact has passed verification.

> This is an independent community project, not an official DeepSeek client.
