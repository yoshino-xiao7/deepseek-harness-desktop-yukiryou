## 简体中文

`v1.0.3` 是 DeepSeek YukiRyou 的稳定版维护更新，重点修复 Workspace Review 在 Runtime 重连后长时间停留在“正在重新确认工作区”的问题，并让账户概览与工作区侧栏都可以由用户明确关闭。

### 本次修复

- **Workspace Review 不再无限等待：** 首次授权请求限制为 2 秒，失败会立即退出阻塞状态；瞬时重连由最多 5 个阶段的后台重试恢复，不会让文件和变更页长期像卡住一样。
- **旧授权不会串入新会话：** Runtime 停止、失败或身份变化时，桌面端会清除旧令牌、工作区能力、文件监视器和重试任务。恢复后只接受当前会话与工作区对应的响应。
- **文件搜索快捷键不再偶发失效：** 从 Harness 切换焦点到 Workspace Review 时立即转发快捷键，不再依赖 Electron 可能缺失的后续焦点事件。
- **Workspace Review 可关闭：** “通用设置”新增默认开启的 Workspace Review 开关。关闭后入口和右栏一起隐藏，并释放现有工作区能力；重新开启后才允许再次展开。
- **账户概览可关闭：** “通用设置”新增默认开启的账户余额开关。关闭后不再显示余额或今日估算消耗，也停止后台查询，方便使用同类插件的用户避免重复功能。
- **保持 Harness 原生样式：** 新增设置项沿用 Harness 通用设置行的字体、字重、间距与颜色；关闭入口继续使用 Harness 自带的纯 `×`，不额外注入中文按钮。
- **可靠保存偏好：** 两个开关使用原子持久化，并处理快速连续点击；重启后保持用户最后一次选择。

## English

`v1.0.3` is a stable maintenance update for DeepSeek YukiRyou. It fixes Workspace Review getting stuck while re-authorizing after Runtime reconnects and makes both the account summary and workspace panel explicitly optional.

### Fixes in this release

- **Workspace Review no longer waits indefinitely:** the initial authority request has a two-second deadline and exits its blocking state immediately on failure. Transient reconnects use at most five bounded background retry stages.
- **Stale authority cannot cross sessions:** stopping, failing, or replacing the Runtime clears old tokens, workspace capabilities, file monitors, and pending retries. Only responses matching the current session and workspace identity can restore the panel.
- **File-search shortcuts no longer fail intermittently:** focus is requested and the shortcut is forwarded immediately when moving from Harness to Workspace Review, without waiting for an Electron focus event that may never arrive.
- **Workspace Review can be disabled:** a default-on switch under General Settings hides the entry and panel, then releases current workspace authority. It cannot be reopened until the switch is enabled again.
- **The account summary can be disabled:** a second default-on switch hides balance and estimated daily usage and stops background queries, avoiding duplication with plugins that provide similar information.
- **Native Harness styling is preserved:** both rows use the typography, spacing, weight, and colors of native General Settings rows. The dialog keeps Harness's original plain `×` close control without injected text.
- **Preferences persist safely:** feature preferences are written atomically and rapid repeated toggles resolve to the latest state across restarts.

### Downloads

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: guided Setup EXE with a selectable destination and a portable ZIP.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

Installations in mainland China prefer `download-cn.suzuki.ink` and fall back to GitHub; other regions prefer GitHub. The China mirror is updated only after the GitHub stable Release is public and every artifact has passed verification.

> This is an independent community project, not an official DeepSeek client.
