## 简体中文

`v1.0.6` 修复插件市场无法接管外部安装插件的问题。此前即使外部插件已通过包名、版本和仓库身份核验，安全预检仍可能错误显示“安装预览已失效或 Runtime 状态发生变化”，导致更新流程无法继续。

### 本次修复

- **恢复外部插件接管与更新：** 修正 Runtime 兼容性快照的 lock 文件路径，外部插件现在可以完成依赖图、包体和冻结 lock 预检，并进入原生确认与受管试启动流程。
- **兼容 Harness 的官方预发布依赖：** 仅当依赖范围明确要求时允许解析 RC 依赖；市场中的根插件仍必须是稳定版、未弃用且不包含安装生命周期脚本。
- **准确处理传递依赖：** 优先选择未弃用版本；没有替代项时允许冻结已弃用的传递依赖。传递依赖声明的 npm 安装脚本不会被执行，根插件的安装脚本仍然严格禁止。
- **兼容真实 npm 归档：** 支持 `@types/node` 使用包名作为归档根目录，以及 `agent-base` 中内容完全相同的点路径重复条目；目录穿越、符号链接、大小写碰撞、内容冲突和 `node_modules` 注入继续被拒绝。
- **保持现有插件能力不变：** 本版本没有修改 Grok、Codex 或 DeepSeek 插件本身，只修复桌面插件市场的安全接管链。

### 已验证插件

- `dsh-codex-community@1.1.0`：95 个 npm 制品及完整依赖图通过校验并生成安装计划。
- `dsh-deepseek-account@0.1.6`：真实 npm 包体通过校验并生成安装计划。

### 下载与升级

- macOS 14+ Apple Silicon：签名并经 Apple 公证的 DMG 与 ZIP。
- Windows 11 x64：Setup EXE 与便携 ZIP。
- `v1.0.5` 已修复上一版的 macOS 退出交接问题；本次发布会重新执行从当前公开版到 `v1.0.6` 的严格应用内下载、安装和重启门禁。

Windows 产物暂未进行 Authenticode 签名，系统可能显示 SmartScreen 警告。请只从本 Release 或官方中国大陆镜像下载，并核对 SHA-256 清单。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.6` fixes marketplace adoption for externally installed plugins. Even after an external package passed package-name, version, and repository identity checks, its safety preview could incorrectly report that the preview had expired or the Runtime state had changed, preventing the update flow from continuing.

### Fixes

- **Restores external adoption and updates:** fixes the Runtime compatibility lockfile path so external plugins can complete dependency-graph, artifact, and frozen-lock inspection before native confirmation and managed trial startup.
- **Supports official Harness prerelease dependencies:** RC dependencies are accepted only when an exact dependency range requires them. Marketplace root plugins must still be stable, non-deprecated, and free of install lifecycle scripts.
- **Handles transitive dependencies accurately:** supported versions are preferred, with deprecated transitive packages accepted only when no eligible replacement exists. Declared npm install scripts in transitive packages are never executed; root-plugin install scripts remain blocked.
- **Supports real npm archive layouts:** accepts package-name archive roots used by `@types/node` and byte-identical dot-path duplicates found in `agent-base`, while continuing to reject traversal, symbolic links, case collisions, conflicting content, and injected `node_modules`.
- **Preserves existing plugin capabilities:** this release does not modify the Grok, Codex, or DeepSeek plugins themselves. It only repairs the desktop marketplace adoption pipeline.

### Verified plugins

- `dsh-codex-community@1.1.0`: all 95 npm artifacts and the complete dependency graph passed verification and produced an installation plan.
- `dsh-deepseek-account@0.1.6`: the real npm artifact passed verification and produced an installation plan.

### Downloads and upgrades

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: Setup EXE and portable ZIP.
- `v1.0.5` fixed the previous macOS exit handoff. This release reruns the strict in-app download, installation, and relaunch gate from the current public version to `v1.0.6`.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

> This is an independent community project, not an official DeepSeek client.
