## 简体中文

`v0.2.3-beta.3` 升级至 DeepSeek Harness `0.1.1-rc.2`，并完善 Windows 桌面体验、账户概览和可持续维护的插件市场来源。

### Harness 与账户

- 内置 Harness 升级到 `0.1.1-rc.2`，加入 Vision Exp 模型、Files API 图片复用、确定性的图片缩放/格式转换及上游沙箱安全修复。
- 首次打开 rc.2 前会为非空 Runtime Home 创建独立回退副本，不覆盖已有 rc.8 历史备份。
- 账户概览默认显示官方账户余额，悬浮后在同一位置切换为本机今日估算消耗；点击同时刷新两项。估算按官方逐请求 usage 与北京时间工作日峰谷费率计算，不冒充官方账单。

### 插件市场

- 可安装与已安装列表现在都能搜索。
- 新增“YukiRyou · 实机验证”来源；名单由独立公开目录动态维护，只收录开发者亲自安装冒烟测试的精确版本。该标记不是代码审计或绝对安全保证，安装仍必须通过完整安全预检和原生确认。
- 修复 dshfind 增长到 10,604 条、107 页后超过旧容量上限而无法读取的问题；当前完整索引为来源 10,604 条、规范化 10,603 条，后续重启可读取 24 小时持久缓存。

### Windows 与界面

- Windows Setup 改为向导式 NSIS 安装器，允许用户选择安装目录；便携 ZIP 继续可直接解压运行。
- Windows 使用与应用主题协调的自绘标题栏和原生窗口按钮；菜单中文/英文跟随 Harness 设置。
- macOS 与 Windows 安装版统一支持后台下载和用户确认后的重启安装；中国大陆优先走受 ESA 保护的 OSS 国内源，其他地区走 GitHub，国内检查或下载失败会自动回退 GitHub。
- GitHub Release 公开且全部门禁通过后才允许同步 OSS；版本化对象回读校验成功后才更新自动更新元数据、官网 `downloads/latest.json` 与国内插件目录。
- 移除重复的“外观”页面，浅色、深色和跟随系统统一使用 Harness 官方“通用设置 → 外观”；未来完整 UI 风格作为声明式插件扩展。
- 开发版与正式版用户数据隔离，避免调试状态污染已安装应用。

### 下载

- macOS 14+ Apple Silicon：签名并经 Apple 公证的 DMG 与 ZIP。
- Windows 11 x64：`DeepSeek.YukiRyou-0.2.3-beta.3-win32-x64-Setup.exe` 与 `DeepSeek.YukiRyou-win32-x64-0.2.3-beta.3-portable.zip`。

Windows 产物暂未进行 Authenticode 签名，系统可能显示 SmartScreen 警告。请只从本 Release 下载并核对 `SHA256SUMS-Windows.txt`。

> 这是社区独立 Beta，不是 DeepSeek 官方客户端。

## English

`v0.2.3-beta.3` upgrades to DeepSeek Harness `0.1.1-rc.2` and improves the Windows desktop experience, account overview, and maintainable plugin-market sources.

### Harness and account overview

- The bundled Harness is upgraded to `0.1.1-rc.2`, adding Vision Exp, Files API image reuse, deterministic image resizing/conversion, and upstream sandbox hardening.
- Before rc.2 first opens a non-empty Runtime Home, the desktop creates a separate rollback copy without replacing the existing rc.8 backup.
- Account overview shows the official balance by default and swaps in the same row to today's local estimated spend on hover. Clicking refreshes both. The estimate uses official per-request usage and Beijing peak/off-peak pricing and is not presented as an official bill.

### Plugin marketplace

- Installable and installed lists are now searchable.
- A new “YukiRyou · Hardware tested” source is maintained dynamically in a separate public catalog and only records exact versions personally installed and smoke-tested by the developer. This is not a code audit or absolute safety guarantee; full pre-install inspection and native confirmation still apply.
- Fixes dshfind becoming unreadable after growing to 10,604 entries across 107 pages. The verified complete scan reports 10,604 provider entries and 10,603 normalized entries, with a 24-hour persistent cache for subsequent launches.

### Windows and interface

- Windows Setup is now a guided NSIS installer with a user-selectable destination. The portable ZIP remains available for extraction-and-run use.
- Windows uses a theme-coordinated custom title bar with native caption controls, and its menu language follows the Harness setting.
- Installed macOS and Windows builds now share background download and confirmed restart-to-install behavior. Mainland China prefers the ESA-protected OSS mirror, other regions use GitHub, and China failures automatically fall back to GitHub.
- OSS synchronization can start only after the GitHub Release is public and all gates pass; mutable updater metadata, the website `downloads/latest.json`, and plugin metadata are published only after versioned objects are uploaded and read-back verified.
- The duplicate Appearance page is removed. Light, dark, and system themes use the official Harness General Settings entry; full UI styles remain a future declarative plugin extension.
- Development and installed builds use separate user-data directories so local debugging cannot contaminate release state.

### Downloads

- macOS 14+ Apple Silicon: Developer ID-signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: `DeepSeek.YukiRyou-0.2.3-beta.3-win32-x64-Setup.exe` and `DeepSeek.YukiRyou-win32-x64-0.2.3-beta.3-portable.zip`.

Windows artifacts are intentionally not Authenticode-signed and may trigger SmartScreen. Download only from this Release and verify `SHA256SUMS-Windows.txt`.

> This is an independent community beta, not an official DeepSeek client.
