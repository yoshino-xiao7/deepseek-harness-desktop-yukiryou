## 简体中文

`v1.0.10` 将内置 DeepSeek Harness 升级到 `0.1.5-rc.2`，并完成桌面端对会话日志 V3、新布局槽位和既有临时补丁的适配。

### Runtime 升级

- **固定 0.1.5-rc.2 完整依赖图：** 内置 `@deepseek-ai/dsh@0.1.5-rc.2`，显式冻结全部非可选 Peer、安装脚本 allowlist 与 npm 完整性，继续提供离线、可复现的 Runtime。
- **新增 V3 Runtime Home 回退代际：** 首次打开非空数据前创建 `runtime.pre-dsh-0.1.5-rc.2[.N]` 副本；既有 `0.1.2-rc.1` 等历史回退副本不会被覆盖或复用。升级后的会话日志不能被旧 Runtime 降级读取。
- **跟随上游 Web 布局：** 官方 `details` 面板已替换为 `rightbar`；对话表面迁入 `main.conversation`。桌面插件继续只使用加法型槽位 `sidebar.footer.action`、`conversation.chat.turnTail`、`conversation.input.dock` 与设置页槽位。

### 随包 Harness 能力

- 新会话默认使用 `DeepSeek-V41-Flash`（`deepseek-flash`）；配置文件显式指定模型时以配置值为准。
- Web 支持任意类型文件上传、官方右侧 Sidebar 文档/文件预览，以及反馈提交确认。
- 本机 Workspace Review 仍由桌面壳独立承载，不占用官方 `rightbar`。

### 安全与兼容性

- 复核临时补丁：模型输入能力、会话选择恢复与上下文容量 Tooltip 在 0.1.5-rc.2 实际 bundle 中仍有必要，已重新定位并保留严格版本保护。上游已覆盖可添加提供方的命名空间过滤，该段补丁已删除。
- 侧栏更新按钮继续使用正式 `sidebar.footer.action`；0.1.5-rc.2 仍命中既有几何选择器。
- macOS/Linux 启动等待与 Windows 对齐为 60 秒，使 Loader 在并发装配失败后能写完诊断，插件隔离仍可按 entry 身份生效。

### 发布门禁

- 本地需完成 Runtime 装配与校验、类型检查、lint、单元测试及真实 0.1.5-rc.2 集成验证。
- 正式发布仍须通过 macOS 签名/公证/安装与更新闭环，以及 Windows 11 x64 Setup/portable 生命周期门禁；未通过前不会覆盖已发布标签。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.10` upgrades the bundled DeepSeek Harness to `0.1.5-rc.2` and adapts the desktop application to session-log V3, the new layout slots, and the existing temporary patches.

### Runtime upgrade

- **Pins the complete 0.1.5-rc.2 dependency graph:** bundles `@deepseek-ai/dsh@0.1.5-rc.2` with every non-optional peer, install-script allowlist entry, and npm integrity value explicitly frozen for reproducible offline startup.
- **Adds a V3 Runtime Home rollback generation:** preserves a non-empty home as `runtime.pre-dsh-0.1.5-rc.2[.N]` before first access without overwriting or reusing older rollback copies. Upgraded session logs cannot be read by an older Runtime.
- **Follows the upstream Web layout:** the official `details` panel is replaced by `rightbar`, and conversation now lives under `main.conversation`. Desktop plugins still use only additive slots: `sidebar.footer.action`, `conversation.chat.turnTail`, `conversation.input.dock`, and the settings slots.

### Bundled Harness capabilities

- New Sessions default to `DeepSeek-V41-Flash` (`deepseek-flash`); an explicit configuration-file model still wins.
- Web gains arbitrary file uploads, the official right Sidebar document/file preview, and confirmed feedback submission.
- Local Workspace Review remains host-owned and does not occupy the official `rightbar`.

### Security and compatibility

- **Revalidates temporary patches:** the model-input capability, session-selection recovery, and context-meter Tooltip patches remain necessary in the actual 0.1.5-rc.2 bundles and retain strict version guards. Upstream now filters addable providers by namespace, so that portion of the model patch is removed.
- The sidebar update action continues to use official `sidebar.footer.action`; the 0.1.5-rc.2 geometry selectors still match.
- macOS/Linux startup wait now matches Windows at 60 seconds so the Loader can finish fail-loud rollback and emit diagnostics that plugin isolation can match.

### Release gates

- Local Runtime vendoring and verification, type checking, lint, unit tests, and real 0.1.5-rc.2 integration checks are required.
- Publication still requires the macOS signing, notarization, installation, and update loop plus the Windows 11 x64 Setup/portable lifecycle gates. Published tags will not be overwritten.

> This is an independent community project, not an official DeepSeek client.
