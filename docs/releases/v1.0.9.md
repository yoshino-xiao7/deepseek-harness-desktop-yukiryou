## 简体中文

本版本围绕应用更新体验、外部插件更新与启动恢复进行改进。

- 仅确认有更新才显示按钮：设置先缩短，更新入口再显现，同一目标版本只播放一次。更新按钮通过正式侧栏槽位呈现，与设置独立响应悬停、按下和键盘焦点。下载期间可查看真实进度，禁止重复触发下载。
- 外部插件的检查更新结果与未挂载安装项可见；有可信 Registry 身份的插件沿用预览、接管、试运行与回退流程。已停用插件更新后保持停用。本地安装不会被擅自替换为同名 npm 包。
- 新增独立安全启动入口。可定位的插件加载故障按包隔离；原因不明确时跳过用户插件和自定义补丁，使用内置配置启动，并保留原数据目录。
- 恢复模式不会自动重新启用隔离项；应用菜单提供恢复管理与逐个试启用。真实加载失败、初始化超时和未完成启动需要与普通进程故障分别判断，不能把安全启动成功解释为所有插件都有问题。

- 修复 Windows 部分显示缩放下重启后窗口逐渐变大的问题，恢复上次保存的窗口位置和尺寸。

## English

This version improves app update feedback, external plugin updates, and startup recovery.

- The update action stays hidden until an update is confirmed. Settings first yields space, then the action appears, once per target release. The update action uses the official sidebar slot, independently of Settings, with hover, press, and keyboard feedback. Download progress stays accessible while duplicate actions are blocked.
- External update results and installations missing from the runtime inventory remain visible. Verified registry packages use the existing inspection, adoption, trial, and rollback transaction. Disabled plugins remain disabled; local packages are not silently replaced by registry packages with the same name.
- A host-owned safe startup skips user bundles and custom patches while retaining the original data home. Loader-identified plugin failures can be isolated separately.
- Recovery persists across restarts. The application menu offers recovery management and individual retry actions; success in safe mode does not establish which plugin caused the failure.

- Restoring saved Windows bounds corrects native frame rounding at fractional display scales, preventing the window from growing across restarts.
