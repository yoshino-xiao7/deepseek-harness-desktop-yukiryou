## 简体中文

`v1.0.12` 修复升级后第三方插件无法连接本机服务的问题。

- 恢复 Codex 插件的登录状态、额度、会话偏好和连接诊断接口。
- 恢复受同一问题影响的 DeepSeek 账户余额等插件接口。
- 补齐宿主 Connection 的 WebServer 依赖，保留浏览器认证、请求来源校验与插件卸载清理。

内置 DeepSeek Harness 继续使用 `0.1.5-rc.2`。此修复不要求重新安装插件或清除已保存的登录信息。

---

## English

`v1.0.12` fixes third-party plugins failing to connect to their local services after an upgrade.

- Restores the Codex plugin's sign-in status, usage, session preferences, and connection diagnostics endpoints.
- Restores other plugin endpoints affected by the same issue, including DeepSeek account balance.
- Declares the host Connection service's missing WebServer dependency while preserving browser authentication, request-origin checks, and route cleanup on plugin unload.

The bundled DeepSeek Harness remains at `0.1.5-rc.2`. This fix does not require reinstalling plugins or clearing saved sign-in information.
