## 简体中文

`v1.0.7` 修复 `v1.0.6` 中插件市场预检全面失败的严重回归，并完善桌面自动更新的下载反馈。

### 本次修复

- **恢复所有插件安全预检：** Runtime 快照现在能区分源码布局和发布包内的 `node_modules/@dsh-desktop/market` 布局，读取正确的固定 lock 文件，不再因为依赖图无法建立而拦截所有插件。
- **恢复外部插件接管与更新：** `dsh-deepseek-account`、`dsh-codex-community` 等外部安装插件可以重新完成真实包体、依赖图、Runtime Peer 与冻结 lock 预检，并进入原生确认后的受管更新流程。
- **加强发布包回归门禁：** `runtime:verify` 会实际加载随包市场插件并读取 Runtime 快照，防止只在源码测试中成立的路径再次进入发布包。
- **改进主页更新入口：** 更新按钮改为向下下载箭头，下载时显示来自原生更新器的真实整数百分比。
- **新增确定型下载进度条：** “关于 → 软件更新”同步显示真实百分比、状态文字和对应填充宽度；更新源无法提供总大小时安全降级为不确定型进度。

### 验证

- `dsh-grok-provider@1.0.2` 与外部 `dsh-deepseek-account@0.1.6` 在真实随包 Runtime 中均完成预检并返回零阻断项。
- 485 项单元测试、48 项集成测试、macOS 本地打包，以及 Windows 安装、启动、修复安装、再次启动与卸载生命周期候选门禁通过。
- 旧版本升级门禁会先在旧版内重载并确认真实活动会话，再关闭旧版并启动候选，避免测试工具自身的 localStorage 回写竞态产生错误失败。

### 下载与升级

- macOS 14+ Apple Silicon：签名并经 Apple 公证的 DMG 与 ZIP。
- Windows 11 x64：Setup EXE 与便携 ZIP。
- 正式发布会执行从当前公开版 `v1.0.6` 到 `v1.0.7` 的应用内下载、安装和重启兼容门禁。

Windows 产物暂未进行 Authenticode 签名，系统可能显示 SmartScreen 警告。请只从本 Release 或官方中国大陆镜像下载，并核对 SHA-256 清单。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.7` fixes the severe `v1.0.6` regression that blocked every marketplace inspection and improves desktop update download feedback.

### Fixes

- **Restores all plugin safety inspections:** Runtime snapshots now distinguish the source layout from the packaged `node_modules/@dsh-desktop/market` layout and read the correct pinned lockfile instead of blocking every plugin when dependency-graph construction fails.
- **Restores external plugin adoption and updates:** externally installed plugins such as `dsh-deepseek-account` and `dsh-codex-community` can again complete real artifact, dependency-graph, Runtime Peer, and frozen-lock inspection before native confirmation and managed updates.
- **Strengthens packaged-runtime regression gates:** `runtime:verify` now loads the packaged marketplace plugin and reads its Runtime snapshot, preventing source-only path assumptions from reaching another release.
- **Improves the homepage update entry:** the update action uses a download arrow and displays the native updater's real integer percentage while downloading.
- **Adds a determinate download progress bar:** About → Software update displays the real percentage, matching status copy, and fill width. It safely falls back to indeterminate progress when the source does not provide a total size.

### Verification

- `dsh-grok-provider@1.0.2` and external `dsh-deepseek-account@0.1.6` both completed inspection against the real packaged Runtime with zero blockers.
- 485 unit tests, 48 integration tests, local macOS packaging, and the Windows candidate lifecycle covering install, launch, repair-install, relaunch, and uninstall all passed.
- The previous-version gate now reloads the old release and confirms the real active session before closing it and launching the candidate, eliminating a false failure caused by the test harness racing its own localStorage writeback.

### Downloads and upgrades

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: Setup EXE and portable ZIP.
- The formal release reruns the in-app download, installation, and relaunch compatibility gate from the current public `v1.0.6` to `v1.0.7`.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

> This is an independent community project, not an official DeepSeek client.
