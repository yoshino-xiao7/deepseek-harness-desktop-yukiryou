# DeepSeek YukiRyou 0.1.1-beta.1

这是 DeepSeek YukiRyou 的首个公开 Beta。它把本机运行的 DeepSeek Harness、固定版本 Node.js 和 pnpm 收进一个可安装的 Apple Silicon macOS 应用，让日常使用不再需要手动启动终端进程或管理本地端口。

## 本版亮点

- **独立桌面体验**：使用原生 macOS 交通灯、可拖动顶栏和单实例窗口承载完整 Harness Web UI。
- **侧栏视觉同步**：顶栏分界会跟随 Harness 侧栏展开、收起与宽度动画，浅色、深色和跟随系统主题保持一致。
- **外观与关于页面**：可切换应用外观、查看版本与运行时信息、访问开发者 GitHub，并在应用内检查更新。
- **品牌与启动体验**：应用正式更名为 DeepSeek YukiRyou，使用 YukiRyou 品牌图标和重新设计的启动动画。
- **本地运行时托管**：内置并固定 DeepSeek Harness `0.1.0-rc.6`、Node.js `24.19.0` 与 pnpm `10.34.5`，不依赖用户全局环境。
- **恢复与诊断**：运行时异常可自动恢复；日志会轮转并脱敏，支持导出不包含项目源码、会话和凭据的诊断包。
- **安全分发**：DMG 与 ZIP 均经过 Developer ID 签名、Apple 公证、Gatekeeper 和全新 runner 安装启动验证。

## 下载与安装

推荐下载 Apple Silicon DMG：

[下载 DeepSeek.YukiRyou-0.1.1-beta.1-arm64.dmg](https://github.com/yoshino-xiao7/deepseek-yukiryou/releases/download/v0.1.1-beta.1/DeepSeek.YukiRyou-0.1.1-beta.1-arm64.dmg)

打开 DMG 后，将 **DeepSeek YukiRyou** 拖入“应用程序”。如果已有旧版本，选择“替换”即可；仓库源码、开发构建以及 Harness 用户配置和会话不会被删除。

系统要求：Apple Silicon Mac（M1 或更新芯片）、macOS 14 或更高版本。

## 更新说明

应用启动后会定期检查更新，也可以在“设置 → 关于”中手动检查。当前版本已经是最新版本时，不会在主界面显示更新按钮。

## 已知限制

- 当前仍为 Beta，建议重要工作保留项目与配置备份。
- 暂不支持 Intel Mac、Windows 或 Linux。
- 本项目由社区独立开发，与 DeepSeek 官方没有隶属或背书关系。

遇到问题请前往 [GitHub Issues](https://github.com/yoshino-xiao7/deepseek-yukiryou/issues) 反馈，并附上 macOS 版本、应用版本和复现步骤。
