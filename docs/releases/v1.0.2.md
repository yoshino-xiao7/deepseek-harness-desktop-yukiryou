## 简体中文

`v1.0.2` 是 DeepSeek YukiRyou 的稳定版维护更新，重点修复 Windows 自动更新初始化，并让更新入口、Workspace Review 和插件市场更清晰地融入当前界面。

### 本次修复

- **Windows 自动更新恢复**：安装版和便携版都会携带 `app-update.yml`，`electron-updater` 可以从固定 GitHub 仓库完成初始化；候选工作流会同时检查包内配置，避免再次发布缺少更新引导文件的产物。
- **启动即检查更新**：桌面更新检查在应用启动后立即开始，不再等待内置 Harness Runtime。即使本地运行时启动缓慢或失败，也不会阻塞新版本发现。
- **更新入口更明确**：主页沿用设置附近的紧凑更新图标，更新卡片则明确显示“下载更新”“下载中”或“重启更新”等动作，不再新增一个重复的文字按钮。确认已经是最新版后主页入口自动隐藏；“设置 → 关于”仍可随时手动检查。
- **Workspace Review 跟随主题**：右侧工作区面板、工具栏表面和滚动条继承当前 Harness 的背景、前景和弱化色，适配浅色、深色及社区主题。
- **已安装插件布局整理**：插件身份、运行状态和操作按钮改为稳定的分区布局；窄窗口下自动纵向排列，减少空白、挤压和按钮错位。

### 下载

- macOS 14+ Apple Silicon：签名并经 Apple 公证的 DMG 与 ZIP。
- Windows 11 x64：可选择安装目录的 Setup EXE 与便携 ZIP。

Windows 产物暂未进行 Authenticode 签名，系统可能显示 SmartScreen 警告。请只从本 Release 或官方中国大陆镜像下载，并核对 SHA-256 清单。

中国大陆自动更新优先使用 `download-cn.suzuki.ink`，失败时回退 GitHub；其他地区优先使用 GitHub。国内镜像只在 GitHub 正式 Release 公开且全部资产校验通过后更新。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.2` is a stable maintenance update for DeepSeek YukiRyou. It restores Windows updater initialization and makes update actions, Workspace Review, and installed plugin management fit the active interface more clearly.

### Fixes in this release

- **Restored Windows updates:** installed and portable builds now include `app-update.yml`, allowing `electron-updater` to initialize against the pinned GitHub repository. Candidate gates verify the packaged bootstrap so a build cannot ship without it again.
- **Update checks start with the app:** desktop update discovery begins immediately and no longer waits for the bundled Harness Runtime. A slow or failed local runtime cannot hide an available desktop update.
- **Recognizable update actions:** the homepage keeps the compact update icon beside Settings, while the update card uses explicit actions such as “Download update”, “Downloading”, or “Restart to update” instead of adding a second text button. The homepage entry disappears once the app is confirmed current; manual checks remain available under Settings → About.
- **Theme-aware Workspace Review:** the workspace panel, toolbar surfaces, and scrollbars inherit the active Harness background, foreground, and muted colors across light, dark, and community themes.
- **Cleaner installed plugin cards:** identity, runtime state, and actions now occupy stable regions, with a responsive single-column layout for narrow windows to prevent empty gaps and displaced buttons.

### Downloads

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: guided Setup EXE with a selectable destination and a portable ZIP.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

Installations in mainland China prefer `download-cn.suzuki.ink` and fall back to GitHub; other regions prefer GitHub. The China mirror is updated only after the GitHub stable Release is public and every artifact has passed verification.

> This is an independent community project, not an official DeepSeek client.
