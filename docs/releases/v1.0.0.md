## 简体中文

`v1.0.0` 是 DeepSeek YukiRyou 的首个稳定版。它继续提供同一套 macOS Apple Silicon 与 Windows 11 x64 桌面工作区，并集中修复账户估算、Windows 启动反馈和插件版本管理中的误导问题。

### 本次修复

- **今日消耗不再始终为 0**：Harness 官方 DeepSeek 路由记录的 provider 是 `deepseek-official`；现在 Flash、Vision Exp 和 Pro 的真实 usage 都能进入本机估算，并继续按北京时间工作日 9:00–12:00、14:00–18:00 峰价及其余半价逐请求计算。
- **Windows 启动反馈**：系统开启“减少动态效果”时仍保留低强度进度脉冲，不再像完全卡住；动画不使用位移，继续尊重无障碍偏好。
- **已安装插件详情**：受管安装收据保留市场来源，已安装列表现在可以读取对应目录中的简介、仓库和分类，并显示本机安装版本、运行状态与安装类型。
- **插件版本不再误导**：安全预检前可选择“安装目录版本”或“安装最新版本”。目录版严格使用市场记录的精确版本；最新版先对账 npm `latest`。两种选择都必须经过完整依赖图、Runtime、包体、完整性和生命周期脚本检查。
- **插件更新入口**：已安装受管插件新增“检查更新”。目录版本、npm 最新版和最终精确包会分开显示；更新、重装和有意版本切换仍由同一套受管事务、原生确认、试运行与失败恢复保护。

### 下载

- macOS 14+ Apple Silicon：签名并经 Apple 公证的 DMG 与 ZIP。
- Windows 11 x64：可选择安装目录的 Setup EXE 与便携 ZIP。

Windows 产物暂未进行 Authenticode 签名，系统可能显示 SmartScreen 警告。请只从本 Release 或官方中国大陆镜像下载，并核对 SHA-256 清单。

中国大陆自动更新优先使用 `download-cn.suzuki.ink`，失败时回退 GitHub；其他地区优先使用 GitHub。国内镜像只在 GitHub 正式 Release 公开且全部资产校验通过后更新。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.0` is the first stable DeepSeek YukiRyou release. It continues to ship one desktop workspace for Apple Silicon macOS and Windows 11 x64 while fixing misleading account estimates, Windows startup feedback, and plugin version management.

### Fixes in this release

- **Today's estimated spend no longer remains at zero:** the official Harness DeepSeek route records `deepseek-official` as its provider. Real usage from Flash, Vision Exp, and Pro is now included, with each request priced against Beijing weekday peak windows (09:00–12:00 and 14:00–18:00) or the half-price off-peak rate.
- **Visible Windows startup feedback:** reduced-motion environments retain a low-intensity progress pulse instead of looking frozen. It uses no positional motion and continues to respect the accessibility preference.
- **Installed plugin details:** managed receipts preserve the marketplace source, allowing the installed view to retrieve descriptions, repositories, and categories while retaining local version, Runtime state, and ownership details as a fallback.
- **Unambiguous plugin versions:** before inspection, choose either the exact catalog version or npm `latest`. Both paths must pass the complete dependency graph, Runtime, artifact, integrity, and lifecycle-script inspection.
- **Plugin update entry:** managed plugins now expose Check for updates. The catalog version, npm latest, and final exact package are shown separately, while updates, reinstalls, and intentional version changes remain protected by the same managed transaction, native confirmation, trial launch, and automatic recovery path.

### Downloads

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: guided Setup EXE with a selectable destination and a portable ZIP.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

Installations in mainland China prefer `download-cn.suzuki.ink` and fall back to GitHub; other regions prefer GitHub. The China mirror is updated only after the GitHub stable Release is public and every artifact has passed verification.

> This is an independent community project, not an official DeepSeek client.
