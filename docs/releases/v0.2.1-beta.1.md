## 简体中文

这是一次补丁 Beta，重点修复自动更新失败后的状态反馈和主页面更新入口位置，并补齐中英文项目文档。

- 当 macOS 签名验证服务拒绝自动更新时，应用会解释失败原因并提供官方已公证 DMG 的下载入口；不会绕过系统安全验证。
- 主页面更新入口固定在展开后的 DeepSeek Harness 品牌行中，不再出现在交通灯下方。

### 文档

- 新增完整英文 README，并在中英文 README 顶部提供语言切换。
- 补充账户余额、Desktop Companion、工作区文件树、Git 变更审核、Markdown/文本/图片预览、安全边界和发布链说明。
- 新增路线图：DeepSeek 宠物标记为“开发中”，手机远程控制和插件市场标记为“规划中”。
- Release Notes 从本版本起在同一个文件内提供简体中文与英文。

### 下载与安装

推荐下载 Apple Silicon DMG：

[下载 DeepSeek.YukiRyou-0.2.1-beta.1-arm64.dmg](https://github.com/yoshino-xiao7/deepseek-harness-desktop-yukiryou/releases/download/v0.2.1-beta.1/DeepSeek.YukiRyou-0.2.1-beta.1-arm64.dmg)

打开 DMG 后，将 **DeepSeek YukiRyou** 拖入“应用程序”。覆盖安装不会删除 Harness 的会话、凭据、设置或工作区数据。

系统要求：Apple Silicon Mac（M1 或更新芯片）、macOS 14 或更高版本。

> 如果系统本身无法验证自动更新签名，请从上述 GitHub Release 下载已公证 DMG 手动覆盖安装。应用不会降低或绕过 macOS 的签名要求。

## English

This patch Beta improves update recovery and the placement of the main-window update entry, and completes the project's bilingual documentation.

### Fixes

- Update downloads now show a continuous indeterminate progress indicator and “Downloading” instead of incorrectly remaining on “Checking.”
- If macOS signature validation rejects an automatic update, the app explains the failure and offers the official notarized DMG. It never bypasses system security validation.
- The main-window update entry now stays in the expanded DeepSeek Harness brand row instead of appearing below the traffic lights.

### Documentation

- Added a complete English README with language links in both README files.
- Documented account balance, Desktop Companion, the workspace tree, Git review, Markdown/text/image previews, security boundaries, and the release pipeline.
- Added a roadmap: the DeepSeek pet is marked “In development,” while mobile remote control and the plugin marketplace are “Planned.”
- Release Notes are now bilingual in one file, starting with this version.

### Download and install

The Apple Silicon DMG is recommended:

[Download DeepSeek.YukiRyou-0.2.1-beta.1-arm64.dmg](https://github.com/yoshino-xiao7/deepseek-harness-desktop-yukiryou/releases/download/v0.2.1-beta.1/DeepSeek.YukiRyou-0.2.1-beta.1-arm64.dmg)

Open the DMG and drag **DeepSeek YukiRyou** into Applications. Installing over an existing copy does not remove Harness sessions, credentials, settings, or workspace data.

Requirements: an Apple Silicon Mac (M1 or newer) running macOS 14 or later.

> If the operating system itself cannot validate the automatic update signature, install the notarized DMG from the GitHub Release above. The app does not weaken or bypass macOS signing requirements.

### Known limitations

- This remains a Beta. Keep backups of important projects and configuration.
- Desktop Companion is read-only and does not provide revert, commit, or push actions.
- The DeepSeek pet is in development; the current installer does not yet include the pet activity area.
- Intel Macs, Windows, and Linux are not currently supported.
- This is an independent community project and is neither affiliated with nor endorsed by DeepSeek.

Please report problems through [GitHub Issues](https://github.com/yoshino-xiao7/deepseek-harness-desktop-yukiryou/issues) with the macOS version, app version, and reproduction steps.
