## 简体中文

`v1.0.5` 将账户侧栏从桌面应用迁移到独立的 `dsh-deepseek-account` 插件，避免桌面版本与账户服务、额度接口或插件发布节奏耦合。

### 本次变更

- 桌面端移除 DeepSeek 余额查询、今日消耗估算、余额 IPC/preload bridge、侧栏账户卡片和“账户余额”功能开关。
- DeepSeek 账户余额与官方网页登录/充值入口由独立 `dsh-deepseek-account` 插件提供。
- 账户插件按当前会话模型只显示一份信息：DeepSeek 显示 Key 余额；Grok 与 Codex 从已安装 Provider 插件读取原有额度数据并只显示重置时间，其中 Codex 额外显示五小时额度。
- Grok 与 Codex 插件未安装时，DeepSeek 余额和充值入口仍可独立使用；无法识别的自定义 Provider 回退到 DeepSeek。
- 本次没有修改 Grok 或 Codex 插件的原有能力，桌面端也不会预装或默认渲染三张账户卡片。
- Workspace Review、插件市场、桌面更新和 companion 的其他能力保持不变。

### 兼容性

- 升级后如需继续查看 DeepSeek 余额，请从插件市场安装 `dsh-deepseek-account`。
- 旧偏好文件可以安全读取，但旧余额 bridge 和 `account.balance` companion RPC 不再提供。
- 本版本不包含任何真实充值付款；登录和付款只在 DeepSeek 官方网页完成。

> 这是社区独立项目，不是 DeepSeek 官方客户端。

## English

`v1.0.5` moves the account sidebar out of the desktop application and into the independent `dsh-deepseek-account` plugin, decoupling desktop releases from account services and quota APIs.

### Changes

- Removes the built-in DeepSeek balance reader, estimated daily spend, balance IPC/preload bridge, sidebar account card, and account-balance preference.
- DeepSeek balance display and the official web sign-in/top-up entry are provided by the separate `dsh-deepseek-account` plugin.
- The account plugin shows one model-specific view: DeepSeek Key balance, or reset times read from an installed Grok/Codex Provider plugin. Codex additionally shows its five-hour limit.
- DeepSeek balance and top-up remain fully functional when Grok or Codex is not installed. Unknown custom Providers fall back to DeepSeek.
- This release does not change the existing capabilities of the Grok or Codex plugins, and the desktop does not preload or render three account cards.
- Workspace Review, the plugin market, desktop updates, and other companion capabilities are unchanged.

### Compatibility

- Install `dsh-deepseek-account` from the plugin market to keep viewing DeepSeek balances after upgrading.
- Legacy preference files remain safely readable, but the old balance bridge and `account.balance` companion RPC are no longer available.
- This release performs no payment transaction. Sign-in and payment occur only on the official DeepSeek website.

> This is an independent community project, not an official DeepSeek client.
