## 简体中文

`v1.0.4` 是 DeepSeek YukiRyou 的稳定版维护更新，重点修复 macOS 下载更新后点击“更新并重启”只退出而没有可靠重新启动的问题，并为经过身份验证的外部顶层插件补充安全的启停与卸载能力。

### 本次修复

- **macOS 更新只在安装真正就绪后提示重启：** 更新 ZIP 下载完成并不等于 Squirrel.Mac 已完成解包和校验。桌面端现在会继续等待 Electron 原生更新器的安装就绪事件，避免过早退出应用。
- **安装后明确重新启动：** 更新器现在显式要求安装完成后重新打开应用；“更新并重启”会交给已就绪的原生安装器处理，而不是只关闭当前进程。
- **真实跨版本升级成为发布门禁：** macOS 从 GitHub 当前上一公开版升级到本次精确候选；Windows 在隔离目录安装本次候选，再升级到单独构建且嵌入真实更高版本号的后继安装包。两端都通过生产更新 provider 执行真实下载和安装，确认旧进程退出、操作系统拉起新版本，并再次运行打包应用冒烟验证。任一环节失败都不会创建 Release Draft。
- **外部顶层插件可以安全管理：** 插件市场可对包身份、版本、真实路径和顶层入口均验证通过的外部插件执行启用、停用和卸载。启停只使用桌面端覆盖配置，卸载通过内置 Harness 官方插件命令完成，并在系统原生确认后重启。
- **危险或含糊的插件继续只读：** 包内子入口、系统插件、依赖项、路径越界、配置损坏或身份不匹配的条目不会获得管理按钮，避免误删整个包或修改插件代码。

## English

`v1.0.4` is a stable maintenance update for DeepSeek YukiRyou. It fixes macOS updates that could close the app without reliably relaunching after the user chose “Update and restart,” and adds safe lifecycle controls for verified top-level external plugins.

### Fixes in this release

- **macOS offers restart only when installation is truly ready:** downloading the update ZIP does not mean Squirrel.Mac has finished unpacking and validating it. The desktop now waits for Electron's native install-readiness event before it exposes the restart action.
- **Relaunch after installation is explicit:** the updater now explicitly requests that the application reopen after installation. “Update and restart” is handed to a ready native installer instead of merely closing the current process.
- **Real cross-version upgrades are a release gate:** macOS upgrades from the current previous public GitHub release to the exact candidate. Windows installs the candidate in an isolated directory, then upgrades it to a separately built successor installer with a genuinely higher embedded version. Both paths use the production update provider for a real download and install, verify that the old process exits and the OS launches the new version, then run another packaged-app smoke check. Any failure prevents creation of the Release Draft.
- **Verified top-level external plugins can be managed safely:** the marketplace can enable, disable, or uninstall external plugins whose package identity, version, real path, and top-level entry all pass validation. Enablement uses a desktop-owned overlay; removal delegates to the bundled official Harness plugin command after native confirmation, then restarts the app.
- **Ambiguous or unsafe entries remain read-only:** nested package entries, system plugins, dependencies, escaped paths, malformed configuration, and identity mismatches never receive lifecycle controls, preventing accidental package removal or plugin-code modification.

### Downloads

- Apple Silicon on macOS 14+: signed and Apple-notarized DMG and ZIP.
- Windows 11 x64: guided Setup EXE with a selectable destination and a portable ZIP.

Windows artifacts are not Authenticode-signed yet and may trigger SmartScreen. Download only from this Release or the official mainland-China mirror and verify the SHA-256 checksums.

Installations in mainland China prefer `download-cn.suzuki.ink` and fall back to GitHub; other regions prefer GitHub. The China mirror is updated only after the GitHub stable Release is public and every artifact has passed verification.

> This is an independent community project, not an official DeepSeek client.
