## 简体中文

`v0.2.3-beta.1` 把 DeepSeek YukiRyou 从 macOS 单平台桌面壳推进为面向 macOS 与 Windows 的桌面工作台，并交付第一版可受管的社区插件市场。

### 主要更新

- **社区插件市场**：支持完整目录索引、搜索、分类、分页和来源管理；可查看目录来源、本机状态与安装前安全预检。
- **受管插件生命周期**：开放安装、更新、同版本重装、启用、停用、上一验证版本回滚与安全卸载。所有写入都经过一次性预览、系统原生确认、冻结依赖图、真实包体验证、离线 generation 和重启后的双健康检查；失败会自动恢复旧版本并阻断已知坏 generation。
- **Workspace Review 增强**：新增文件和变更搜索、筛选、顺序审阅、前进/后退、预览内查找、路径与行号复制；文件、文件夹和代码行可通过拖放或右键加入当前对话，并保持工作区相对引用。
- **桌面体验修复**：侧栏在窄窗口覆盖、宽窗口停靠，不再挤压或遮挡对话；修复宽度拖动状态、深色菜单对比度、长行 diff、空白预览、主题同步和窗口拖动区域。
- **Windows 11 x64 支持**：新增平台化 Runtime、ConPTY、Windows 图标、Squirrel 安装包和独立候选流水线。真实 Windows runner 已验证打包应用启动/重启、会话恢复、首次安装、同版本修复安装、卸载、快捷方式/注册项清理和用户数据保留。

### 安全说明

社区目录只提供发现能力，不表示官方认可或安全审核。安装前会核验目录与 npm 精确身份、仓库回链、废弃状态、安装生命周期脚本、SHA-512、官方 tarball、平台约束、DSH bundle、Node、完整依赖图、Peer 兼容性和实际包体。插件安装后仍与 Harness 共享本机用户权限，请只安装你信任的代码。

### 下载与平台状态

macOS 公开版继续面向 Apple Silicon、macOS 14 或更高版本，并通过 Developer ID 签名和 Apple 公证。发布后可从本 Release 下载：

`DeepSeek.YukiRyou-0.2.3-beta.1-arm64.dmg`

Windows 11 x64 与 macOS 进入同一个 GitHub Release，提供两份未签名 Beta 产物：

- `DeepSeek.YukiRyou-0.2.3-beta.1-win32-x64-Setup.exe`
- `DeepSeek.YukiRyou-win32-x64-0.2.3-beta.1-portable.zip`

EXE 用于正常安装，ZIP 解压后可直接运行。两者都来自同一提交、携带同一固定 Runtime，并附 `SHA256SUMS-Windows.txt`。当前不做 Authenticode 签名，Windows 可能显示 SmartScreen 警告；请只从本 Release 下载并核对 SHA-256。真实跨版本升级、自动更新闭环和独立 Windows 11 客户端验收继续作为后续质量门，而不是本次未签名 Beta 的发布阻塞项。

> 这是社区独立 Beta，不是 DeepSeek 官方客户端。覆盖安装不会主动删除 Harness 会话、凭据、设置或工作区数据；重要工作仍建议保留备份。

## English

`v0.2.3-beta.1` advances DeepSeek YukiRyou from a macOS-only shell into a desktop workspace for macOS and Windows, and ships the first managed community plugin marketplace.

### Highlights

- **Community plugin marketplace:** complete catalog indexing, search, categories, pagination, source management, provenance details, local status, and pre-install security inspection.
- **Managed plugin lifecycle:** install, update, same-version reinstall, enable, disable, rollback to the previous verified version, and safe removal. Every mutation passes through a single-use preview, native confirmation, a frozen dependency graph, real artifact verification, offline generations, and post-restart dual-health checks. Failed generations are automatically rolled back and blocked.
- **Workspace Review improvements:** file and change search, filters, sequential review, back/forward navigation, find-in-preview, and path/line copying. Files, folders, and code lines can be dragged or added from a context menu as workspace-relative conversation references.
- **Desktop fixes:** the workspace panel overlays narrow windows and docks on wider layouts without covering the conversation. Resizing state, dark-menu contrast, long diff lines, empty previews, theme synchronization, and draggable chrome are also corrected.
- **Windows 11 x64 support:** platform-aware Runtime assembly, ConPTY, Windows icons, Squirrel packaging, and a dedicated candidate pipeline. A real Windows runner now verifies packaged startup/restart, session restoration, first install, same-version repair, uninstall, shortcut/registry cleanup, and user-data retention.

### Security note

Catalog inclusion is discovery, not endorsement or a security audit. Preflight verifies exact catalog/npm identity, repository backlinks, deprecation state, lifecycle scripts, SHA-512 integrity, official tarball origin, platform constraints, the DSH bundle, Node compatibility, the complete dependency graph, peer compatibility, and actual package bytes. Installed plugins still share the local user's permissions with Harness; install only code you trust.

### Downloads and platform status

The public macOS build remains for Apple Silicon on macOS 14 or later and is Developer ID signed and Apple-notarized. After publication, download:

`DeepSeek.YukiRyou-0.2.3-beta.1-arm64.dmg`

Windows 11 x64 ships in the same GitHub Release as macOS with two unsigned beta assets:

- `DeepSeek.YukiRyou-0.2.3-beta.1-win32-x64-Setup.exe`
- `DeepSeek.YukiRyou-win32-x64-0.2.3-beta.1-portable.zip`

The EXE installs normally; the ZIP runs after extraction. Both come from the same commit, contain the same pinned Runtime, and are covered by `SHA256SUMS-Windows.txt`. They are intentionally not Authenticode-signed, so Windows may show a SmartScreen warning. Download only from this Release and verify SHA-256. Real cross-version upgrades, the automatic-update loop, and independent Windows 11 client acceptance remain follow-up quality gates rather than blockers for this unsigned beta.

> This is an independent community beta, not an official DeepSeek client. Installing over an existing copy does not proactively remove Harness sessions, credentials, settings, or workspace data; keep backups of important work.
