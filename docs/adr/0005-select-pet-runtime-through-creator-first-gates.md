# 以普通用户制作能力作为宠物运行时前置门禁

宠物运行时不能只按官方角色画质和播放性能选型。任何候选在进入真机性能比较前，必须先通过同一项创作者门禁：项目维护的自动化流程能够从角色参考图与自然语言动作要求生成、验证并打包宠物，普通用户不需要编写代码、手工绑定骨骼、构建状态机、遵守引擎文件命名或购买并学习专有动画编辑器。更多视角和分层素材只能用于提升结果，不能成为最低可用路径的强制条件。

这意味着 Rive、dotLottie、透明视频或自有格式都只是 `PetPlayer` 内部 Adapter 候选；专业工具可以用于研究和可选精修，但依赖手工专有编辑器导出的候选不能成为唯一 production runtime。Phase 6D 必须先做端到端 Authoring PoC，再做播放 benchmark；Phase 7 负责把已经验证的流程产品化为 Pet Authoring Skill，而不是在格式冻结后才第一次发现自动化不可行。

代价是最自然的专业 rig 方案可能被淘汰，或者项目需要投入更多自动生成、身份一致性和 QA 工程；收益是用户生态不会被锁进只有动画师才能使用的格式，官方宠物与用户宠物也能通过同一套可复刻交付路径。
